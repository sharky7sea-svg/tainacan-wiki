# ファイルの挿入と編集

Tainacanのアイテムでは、外部ソースへのURLを設定することもできますが、通常は画像、動画、音声、PDFなどのファイルをドキュメントとして設定し、WordPressのデータベースに保存します。さらに、このアイテムに関する情報を提供する添付ファイル（これもファイル）を追加できます。このページでは、これらのファイルを投稿するために行えるいくつかの処理、ファイルからアイテムを一括追加する方法、WordPressの _管理画面_ から画像を直接編集する方法について説明します。

## 投稿フローを理解する

Tainacanで使用するすべてのファイルは _「WordPressメディアライブラリ」_ でも表示できますが、メディアライブラリで行う挿入フローとTainacan自体で行う挿入フローには違いがあります。次の画像は、内部で何が起きているかを理解するのに役立ちます。

![ファイルアップロードのフローの違い](pt-br/_assets/images/uploads.png  ':class=alignwide')

ファイルを _「WordPressメディアライブラリ」_ に直接送信すると、WordPressのアップロードフォルダー構造に保存されます。この構造では、ファイルは次に示すような日付別のフォルダーシステムで整理されます。この整理方法は、WordPress自体の設定またはプラグインの使用によって変更できます。

> [!NOTE]
> ただし、Tainacanのアイテムにドキュメントまたは添付ファイルを追加する場合、Tainacanが開くメディアモーダルから送信すると、コレクションと現在のアイテムのIDを使用する別の構造にファイルが保存されます。そのため、Tainacanのアイテム編集画面からメディアモーダルを開くと、そこにはアイテムに関連付けられたファイルと、新しいファイルを送信するオプションだけが表示されます。

このようにして、たとえばファイルの公開状態を確保できます（これは[この記事で説明されているように](/ja/optimization#wordpressのセキュリティ強化)さらに改善できます）。非公開アイテムには異なる先頭文字 `\_x\_` が付くことに注意してください。

> [!WARNING]
> この構成によって、たとえば1つのファイルを2つのアイテムで使用することができなくなります。しかし、これは重要です。この制限がなければ、あるアイテムが公開で別のアイテムが非公開になる可能性があるため、ファイルの公開状態を保証できないからです。

したがって、次のようになります。

1. ファイルをアイテムで使用するには、そのアイテム専用に送信する必要があります。
2. _「WordPressメディアライブラリ」_ に直接送信したファイルは、公開リンクを通じてのみアイテムから参照できますが、「
   アイテムに属する」ことはありません。

WordPressの管理画面に入るとすぐにアクセスできるため、メディアライブラリに送信したファイルをアイテムで使いたいと思うのは一般的です。また、複数のファイルをアイテムごとに送信するのは面倒なことがあります。しかし、この問題を解決する方法が2つあります。後で説明する[ファイルからのアイテムの一括追加](#ファイルの一括追加)と、[CSVによるファイルと添付ファイルのインポート](/ja/importers#ファイルと添付ファイルのインポート)です。

## WordPressメディアライブラリ

前述のとおり、Tainacanで使用するすべてのファイルは _「WordPressメディアライブラリ」_ に保存され、画像ファイルを編集することもできます。

### 画像の挿入

1. _WordPress_ の _「管理画面」_ にアクセスします。

2. 左側のサイドバーで _「メディア」_、次に _「ライブラリ」_ をクリックします。

3. _「メディアライブラリ」_ 画面の左上にある _「新規追加」_ をクリックします。

4. 追加する _「画像」_ をドラッグするか選択します。

   ![メディアライブラリへの画像の挿入](_assets/gifs/inserindo-imagens-biblioteca.gif)

### 画像の編集

1. _WordPress_ の管理画面にアクセスします。

2. 左側のサイドバーで `メディア`、次に `ライブラリ` をクリックします。

3. 編集する画像を選択します。

4. `画像を編集` をクリックします。

5. 必要な編集を行います。

   **「切り抜き」**；

   **「左に回転」**；

   **「右に回転」**；

   **「上下反転」**；

   **「左右反転」**；

   **「画像の拡大・縮小」**；

   **「画像の切り抜き」**。

![メディアライブラリへの画像の挿入](_assets/gifs/editando-imagens-biblioteca.gif)

## アイテムへの画像の挿入

画像は、あらかじめメディアライブラリに追加しなくても、アイテムに直接挿入できます。この操作には3つの方法があります。

- **各アイテムに画像を個別に挿入する；**
- **アイテムの集合に画像を順次挿入する；**
- **画像を一括挿入する。**

画像を個別に挿入する操作は、画像を追加するアイテムが少ない場合に適しています。画像の順次挿入は、2件から同じページにあるすべてのアイテムまでを含むアイテムの集合に適しています。一方、画像の一括挿入は、多数のアイテムを対象とします。

### 画像を個別に挿入する

1. _WordPress_ の管理画面にアクセスします。

   ![管理画面へのアクセス](_assets\images\050.png)

2. 左側のサイドバーで _「Tainacan」_ をクリックします。

   ![管理画面へのアクセス](_assets\images\051.png)

3. コレクションを選択します。

4. 目的の _「アイテム」_ を選択し、 _「アイテムを編集」_ をクリックします。

   ![管理画面へのアクセス](_assets\images\selecione_a_imagem.png)

5. _「ファイル」_ をクリックします。

   ![管理画面へのアクセス](_assets\images\138.png)

6. _「メディアライブラリ」_ にすでにある _「画像」_ を選択するか、コンピューターから _「画像」_ を送信します。

- **「更新」**： _「アイテム」_ に加えた変更を確定します。

### 画像を順次挿入する

4. 編集する _「アイテム」_ の _「チェックボックス」_ をクリックします。
