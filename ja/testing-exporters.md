# エクスポーターのテスト

Tainacanには複数のエクスポーターがあります。開発者がプラグインとして作成できるものも含まれます。このドキュメントでは、最もよく使われていると考えられる[CSVエクスポーター](/ja/exporters)を扱います。

## 基本

1. リポジトリのメニューからアクセスできる、エクスポーターのページに移動する；
2. CSVエクスポーターを選択する；
3. テストするエクスポート元コレクションを選択する；
4. `実行（Executar）`をクリックしてエクスポーターを実行する；
   - [x] エクスポーターの実行が完了したら、プロセスページでログ（ログファイル）を確認し、警告がなかったか確認する。
   - [x] 生成されたファイルをダウンロードして開き、メタデータの値と特殊フィールドを含め、データが正しくエクスポートされたことを確認する。

> [!NOTE]
> 見つかった問題は、[GitHubのissue](https://github.com/tainacan/tainacan/issues ":ignore")またはTainacanの[コミュニティフォーラム](https://tainacan.discourse.group ":ignore")に報告できます。ページが読み込まれないなどの一般的なエラーは、[FAQページの提案](/ja/faq#エラーを見つけたと思います。どうすればよいですか？)を使用すると、より詳しく説明できます。
