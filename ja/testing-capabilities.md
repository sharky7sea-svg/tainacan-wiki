# 権限のテスト

権限とユーザー権限グループの管理は、リポジトリのセキュリティに関わる重要な問題を含むため、Tainacanでテストすべき最も重要な機能の一つです。これらのテストを行うには、理想的にはWordPressの管理者であり、さまざまなテストユーザーを作成・変更する権限が必要です。

## 基本

1. Tainacanプラグインのテストバージョンがインストールされ、有効化されている**WordPressの管理画面**にアクセスする（通常は、サイトのアドレスに`/wp-admin`を加えたもの）；
2. 左側のサイドバーで、**ユーザー**セクションの**新規追加**をクリックする；
3. 任意のデータを入力してテストユーザーを作成し、ユーザー権限グループとして`購読者（Assinante）`を選択する；
4. 右上隅のユーザーメニューにある`ログアウト（Sair）`をクリックして_ログアウト_する；
5. 作成したユーザーでWordPressの管理画面にログインする；
6. 左側のサイドバーで**Tainacan**をクリックし、Tainacanの管理画面にアクセスする；
   - [x] プラグインのホーム画面で、次の項目にアクセスできないことを確認する：
     - リポジトリレベルのメタデータとフィルターへのリンク；
     - コレクションレベルのメタデータ、フィルター、アクティビティへのリンク；
   - [x] 一方で、次の項目が利用できることを確認する：
     - リポジトリレベルのタクソノミー、アクティビティ、インポーター、エクスポーターへのリンク；
     - コレクション一覧へのリンクと、各コレクションのアイテム一覧へのリンク；
7. リポジトリのいずれかのコレクションのアイテム一覧にアクセスする；
   - [x] 次の項目にアクセスできないことを確認する：
     - 新しいアイテムを追加するボタン；
     - 非公開アイテム；
     - アイテムを編集または削除するリンク；
     - アイテムを選択して一括編集するオプション；
     - コレクションのメニューにある、コレクションのメタデータ、アクティビティ、フィルター、権限へのリンク；
   - [x] 次の項目が利用できることを確認する：
     - アイテム一覧の横にあるフィルター；
     - 公開済みアイテム、下書き、ゴミ箱のタブ；
     - 並び順や表示モードなど、検索の操作オプション；
8. いずれかのアイテムをクリックして、管理画面でそのページにアクセスする；
   - [x] アイテムを編集するリンクがないことを確認する；
   - [x] 一覧に表示されないアクティビティを除き、アイテムのすべてのデータが表示されるか確認する；
9. リポジトリのサイドメニューから利用できるコレクション一覧に移動する；
   - [x] 次の項目にアクセスできないことを確認する：
     - 新しいコレクションを追加するボタン；
     - 非公開コレクション；
     - コレクションを編集または削除するリンク；
   - [x] 次の項目が利用できることを確認する：
     - 公開済みコレクションとゴミ箱のタブ；
     - 並び順とテキスト検索のオプション；
10. リポジトリのサイドメニューから利用できるタクソノミー一覧に移動する；

- [x] 次の項目にアクセスできないことを確認する：
  - 新しいタクソノミーを追加するボタン；
  - 非公開タクソノミー；
  - タクソノミーを編集または削除するリンク；
- [x] 次の項目が利用できることを確認する：
  - 公開済みタクソノミー、下書き、ゴミ箱のタブ；
  - 並び順とテキスト検索のオプション；

11. いずれかのタクソノミーを選択してクリックする；

- [x] タクソノミーを編集するタブにアクセスする権限がないことを確認する；
- [x] ターム一覧のタブにはアクセスできるが、タームを追加または編集できないことを確認する；

12. リポジトリのサイドメニューから利用できるリポジトリのアクティビティ一覧に移動する；

- [x] アクティビティタブにアクティビティが一覧表示されないことを確認する；
- [x] プロセスタブに実行中のプロセスがないことを確認する（権限がないためではなく、この新しく作成したユーザーにはプロセスがないため）；

## ユーザー権限グループにすべての権限を追加

1. 管理者としてログインし、Tainacanプラグインのテストバージョンがインストールされ、有効化されている**WordPressの管理画面**にアクセスする（通常は、サイトのアドレスに`/wp-admin`を加えたもの）；
2. 左側のサイドバーで、**Tainacan**セクションの**ユーザー権限グループ**をクリックする；
3. 権限グループ一覧で、「購読者（Assinante）」または権限を付与・削除したい任意の権限グループを探す；
4. 権限グループにマウスポインターを合わせ、**編集**を選択する；
5. 権限グループの編集画面で`Tainacanを管理（Gerenciar Tainacan）`オプションを選択する；
   - [x] `Tainacanを管理（Gerenciar Tainacan）`という上位権限の影響を受けるため、その他のすべての権限が選択され、変更できないことを確認する；
6. `変更を保存（Salvar Alterações）`をクリックする；
7. 右上隅のメニューにある`ログアウト（Sair）`をクリックして_ログアウト_する；
8. 管理画面で、変更した権限グループを持つテストユーザーでログインする；
9. 左側のサイドバーで**Tainacan**をクリックし、Tainacanの管理画面にアクセスする；
   - [x] 今度はTainacanのすべての要素と機能にアクセスできることを確認する；
10. 右上隅のWordPressロゴをクリックして、WordPressの管理画面に戻る；
11. 右上隅のメニューにある`ログアウト（Sair）`をクリックして_ログアウト_する；

## ユーザー権限グループにいくつかの権限を追加

1. もう一度管理者としてログインし、選択した権限グループの設定画面に再度アクセスする（_例：購読者（Assinante）_）；
2. 権限グループの編集画面で`Tainacanを管理（Gerenciar Tainacan）`オプションの選択を解除する；

- [x] すべての権限の選択が解除され、変更できるようになったことを確認する；

3. 「コレクション」タブに切り替える；
4. `すべてのコレクション（Todas as Coleções）`が選択された状態で、次の権限を有効にする：
   1. メタデータを管理する；
   2. フィルターを削除する；
   3. 非公開アイテムを表示する；
5. セレクターを特定のコレクションに切り替える；

- [x] `すべてのコレクション`レベルで選択されている権限は、すでに選択されていて変更できないことを確認する；

6. このコレクションで、次の権限を選択する：
   1. アイテムを一括編集する；
   2. アイテムを編集する；
   3. 公開済みアイテムを編集する；
   4. 他のユーザーのアイテムを編集する；
   5. アイテムを削除する；
7. `変更を保存（Salvar Alterações）`をクリックする；
8. 右上隅のメニューにある`ログアウト（Sair）`をクリックして_ログアウト_する；
9. 管理画面で、変更した権限グループを持つテストユーザーでログインする；
10. 左側のサイドバーで**Tainacan**をクリックし、Tainacanの管理画面にアクセスする；

- [x] プラグインのホーム画面で、次の項目にアクセスできないことを確認する：
  - リポジトリレベルのメタデータとフィルターへのリンク；
  - コレクションレベルのアクティビティとフィルターへのリンク；
- [x] 一方で、次の項目が利用できることを確認する：
  - リポジトリレベルのタクソノミー、アクティビティ、インポーター、エクスポーターへのリンク；
  - コレクション一覧へのリンクと、各コレクションのアイテム一覧およびメタデータ一覧へのリンク；

11. 手順 **5** で設定したコレクションに入る；

- [x] 次の項目にアクセスできないことを確認する：
  - アイテムを削除するリンク；
  - コレクションのメニューにある、アクティビティ、フィルター、コレクションの権限へのリンク；
- [x] 次の項目が利用できることを確認する：
  - 新しいアイテムを追加するボタン；
  - アイテムを編集するリンク；
  - アイテム一覧の横にあるフィルター；
  - 公開済み、非公開、下書き、ゴミ箱のアイテムタブ；
  - 並び順や表示モードなど、検索の操作オプション；
  - アイテムを選択して一括編集するオプション；
  - コレクションのメタデータへのリンク；

12. このコレクションのいずれかのアイテムに入る；

- [x] アイテムを編集するリンクがあることを確認する；
- [x] 一覧に表示されないアクティビティを除き、アイテムのすべてのデータが表示されるか確認する；

13. 「アイテムを編集」をクリックする；

- [x] このアイテムは別のユーザーが作成したため、アイテムを削除するリンクがないことを確認する；

14. アイテム一覧に戻り、「新規追加」をクリックして新しいアイテムを作成する；
15. 任意の内容でアイテムに入力する；

- [x] 「アイテムを公開する」権限がないため、新しいアイテムを下書きとしてのみ保存できることを確認する；

16. 完了したら、アイテム一覧に戻る；

- [x] 作成したアイテムが下書きタブにあり、編集だけでなく削除もできることを確認する；

17. 最後に、コレクションのメタデータ画面に入る；

- [x] メタデータの順序変更と編集はできるが、削除はできないことを確認する；

> [!NOTE]
> 原文では、このテスト手順の記述を続ける必要があるとされています。

## コレクションで特定の権限を設定

1. 管理者としてWordPressの管理画面に入る；
2. 左側のサイドバーで**Tainacan**をクリックし、Tainacanの管理画面にアクセスする；
3. 設定したいコレクションのページに入る；
4. コレクションのメニューから、コレクションに関連する権限のページにアクセスする；
5. 変更する権限を選択する。たとえば「アイテムを一括編集する」；
6. いずれかのユーザー権限グループについて、この権限を削除または追加する；
7. _ログアウト_し、変更したユーザー権限グループのユーザーでログインする；

- [x] 権限が変更されたか確認する；
