# アイテム投稿のテスト

バージョン0.17以降、Tainacanでは、サイトにログインしていないユーザーが公開ページからアイテムを投稿できます。この機能の詳しい説明については、[アイテム投稿](/ja/item-submission)ページを参照してください。

## 基本

1. コレクションを開く；
2. コレクションの設定で「アイテム投稿を許可」オプションを有効にする；
3. デフォルトのステータスなど、その他の設定は変更しない；
4. 設定を保存する；
5. WordPressの管理画面で新しい固定ページを作成する；
6. このページに「アイテム投稿フォーム」ブロックを挿入する；
7. 前の手順で使用したコレクションを選択し、投稿先のコレクションを設定する；
8. これが完了したら、次のことを確認する：
   - [x] コレクション選択モーダルに他のコレクションが一覧表示されていないことを確認する。「アイテム投稿を許可」に設定されたコレクションだけが表示されるはずである；
   - [x] コレクションを選択すると、そのすべてのメタデータがブロックのサイドバーに一覧表示され、必須メタデータを除いて一部を無効または有効にできることを確認する；
9. ページを公開し、公開側でフォームが読み込まれて、次のテストを開始できることを確認する。

## フォームへの入力

1. 公開したフォームのページにアクセスする；
2. メタデータフィールドに入力する；
3. さまざまな種類のドキュメントの投稿をテストする；
4. サムネイルを自動生成する場合と生成しない場合をテストする；
5. さまざまな種類の添付ファイルの投稿をテストする；
   - [x] ここでは無効な添付ファイル形式（たとえば、デフォルトでは`.SVG`は受け付けられないことが多い）も投稿し、投稿時にエラーが発生するか確認する；
6. タクソノミータイプのメタデータフィールドへの入力をテストする；
7. 数値または日付タイプのメタデータフィールドに無効な値を入力するテストを行う；
8. _別のコレクション_のリレーションシップメタデータへの入力をテストする。

   - [x] リポジトリレベルとコレクションレベルのすべてのメタデータが、入力用に正しく表示されるか確認する；
   - [x] 特定のメタデータに設定した入力ヒントが正しく表示されるか確認する；
   - [x] **必須メタデータの入力**に関する警告が、アイテムを**保存**するときに正しく機能するか確認する（デフォルトで下書きになるよう設定されている場合を除く）；

9. 複数の値を受け付ける_複合メタデータ_への入力をテストする。最初はフィールドが空で、値を追加するボタンだけが表示される。追加すると、子メタデータを含む最初の入力グループが表示される。

   - [x] 必須としてマークされた子メタデータが、フォームのエラー一覧にエラーを生成するか確認する；
   - [x] 子メタデータの表示順が、メタデータ設定画面で設定した順序になっているか確認する。

10. _「アイテムの作成者をデフォルトとして設定」（Definir o item do autor como padrão）_機能を、ユーザーメタデータタイプについてテストする。アイテムを作成すると、このフィールドに入力された状態になるはずである。
11. 投稿が完了したら、管理画面に入り、アイテムがコレクションに設定されたデフォルトのステータスで作成されたか確認する。

## その他の投稿設定のテスト

1. コレクションの設定ページに再度アクセスする；
2. 投稿されたアイテムのデフォルトステータスを設定する；
3. 「匿名ユーザーによる投稿を許可」オプションを有効にする；
4. WordPressからログアウトし、ユーザーがまったくログインしていないことを確認する；
5. フォームへの入力テストを繰り返す；
6. 再度ログインし、アイテムが正しいステータスで投稿されているか確認する；

## reCAPTCHA保護のテスト

1. コレクションの設定で「投稿フォームでreCAPTCHA検証を使用」オプションを有効にする；
2. WordPressの管理画面で、Tainacanプラグインの「アイテム投稿」というサブメニューにアクセスする；
3. [Googleの_reCAPTCHA_](https://www.google.com/recaptcha/admin/create ":ignore")フォームで生成した「サイトキー」と「シークレットキー」を、このページのフィールドに入力する；
4. 設定を保存する；
5. 新しい投稿ブロックを挿入する（必要であれば既存のものを削除する）。その際、_reCAPTCHA_が有効になっているコレクションを投稿先として選択することを忘れない；
6. フォームに入力する。ページの最後にreCAPTCHAのチェックボックスがあるはずである。チェックせずに投稿してから、チェックして投稿してみる。

## ブロック設定のテスト

1. サイドバーにあるブロックのその他のオプションを変更してみる：
   1. 投稿が成功したときに表示されるメッセージを編集する；
   2. フォームのセクションのラベルを編集する；
      - [x] ラベルを空白にすると、そのラベルが表示されなくなることを確認する；
   3. 必須ではないメタデータをいくつか非表示にする；
   4. フォームの要素をいくつか非表示にする：
      - [x] 特に、折りたたみを表示しないオプションを試す；
      - [x] ドキュメントタイプ（ファイル、テキスト、URL）の選択肢を2つ以上非表示にすると、ドキュメントを選択するボタンが消え、残った1種類のドキュメントの入力だけが表示されることを確認する；
   5. いくつかの色とフォントサイズを変更してみる；
2. ページを公開し、フォームブロックへの影響を確認する；
