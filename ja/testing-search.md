# アイテム検索のテスト

アイテムのファセット検索をテストするには、メタデータタイプ、フィルター、そしてもちろんアイテムについて、最低限の多様性を持つコレクションが必要です。この準備には、[テストインポーター](/ja/importers#テストインポーター)を使ってコレクションを作成することをおすすめします。準備ができたら、次の手順を行います：

## 基本

1. コレクション、またはリポジトリレベルのアイテム一覧にアクセスする；
2. 単純なテキスト検索を適用する；
3. フィルターのさまざまな組み合わせを適用する；
4. 一覧の並び順と表示モードを変更する（利用できる場合は「全画面」モードも忘れずにテストする）；
5. 複数のページを移動する；
   - [x] 適用したフィルターと検索によって、整合性のある結果が返されることを確認する；
   - [x] ファセット（各フィルター値の横に表示される数字）が正しいことを確認する；
   - [x] フィルターを適用したときにタグが表示されるか確認する（タグを削除すると適用したフィルターも削除されるか確認する）；
   - [x] 適用した検索のURLを選択してコピーし、別のブラウザータブに貼り付け、すべての設定が維持されているか確認する；
6. 上記の手順を、管理画面のアイテム一覧とテーマのアイテム一覧の両方で繰り返す。

## 高度な検索

1. コレクション、またはリポジトリレベルのアイテム一覧にアクセスする；
2. 高度な検索を開く；
3. 各メタデータタイプについて、異なる演算子を組み合わせた検索条件を作成する；
   - [x] 実際に特定の結果が得られる検索を作成してみる；
   - [x] 各条件を削除して検索を再適用したとき、新しいアイテムが表示されるか確認する；
   - [x] 適用した検索のURLを選択してコピーし、別のブラウザータブに貼り付け、すべての設定が維持されているか確認する；
4. 上記の手順を、管理画面のアイテム一覧とテーマのアイテム一覧の両方で繰り返す。

## エクスポーザー

1. コレクション、またはリポジトリレベルのアイテム一覧にアクセスする；
2. 最初のテストで行ったように、いくつかのフィルターを適用する；
3. 「表示形式...（View as...）」ボタンをクリックして、エクスポーザーのモーダルを開く；
   - [x] サイトのアイテム一覧へのリンクが正しいか確認する；
   - [x] 利用可能なエクスポーザー（PDF、HTML、CSV）が、アイテム一覧を反映したリンクを生成しているか確認する；
   - [x] 「表示対象のメタデータのみを出力」チェックボックスを適用したとき、表示対象としてマークされていないメタデータが結果の一覧から除外されるか確認する；
4. 上記の手順を、管理画面のアイテム一覧とテーマのアイテム一覧の両方で繰り返す。
