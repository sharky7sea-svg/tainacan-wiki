# Tainacanの権限

Tainacanの権限は、*リポジトリ*と*コレクション*の2つのレベルに分かれています。主な違いは、コレクションの権限がリポジトリ内のすべてのコレクションを対象にすることも、特定の各コレクションを対象にすることもできる点です。

一部の権限は「上位権限」とみなされるため、別の権限と同等のアクセスを保証できます。たとえば「Tainacanを管理」権限を持つユーザーは、他の権限を持つ必要がありません。この権限によって、すべてのリソースへのアクセスが付与されるためです。以下で各権限を説明します。


<!-- tabs:start -->

### ** リポジトリレベル **

## リポジトリ

### リポジトリ全般
| 名前 | 説明 |
|-----------------------------------|---------------|
| Tainacanを管理 | Tainacanのすべてのリソースとすべてのコレクションを管理 |
| ユーザー権限を管理 | [ユーザー権限グループと権限を管理](/ja/manage-user-roles) |


### タクソノミー
| 名前 | 説明 |
|------------------------------|--------------|
| タクソノミーを編集 | タクソノミーとそのタームを作成・編集 |
| タクソノミーを削除 | タクソノミーとそのタームを削除 |
| 他のユーザーのタクソノミーを編集 | 他のユーザーが作成したタクソノミーとタームを編集 |
| 他のユーザーのタクソノミーを削除 | 他のユーザーが作成したタクソノミーとタームを削除 |
| 非公開タクソノミーを表示 | 非公開タクソノミーとそのタームにアクセス |

### メタデータ
| 名前 | 説明 |
|------------------------|--------------|
| メタデータを編集 | リポジトリレベルのメタデータを作成・編集 |
| メタデータを削除 | リポジトリレベルのメタデータを削除 |
| 非公開メタデータを表示 | リポジトリレベルで非公開メタデータにアクセス |
  
### フィルター
| 名前 | 説明 |
|----------------------|--------------|
| フィルターを編集 | リポジトリレベルのフィルターを作成・編集 |
| フィルターを削除 | リポジトリレベルのフィルターを削除 |
| 非公開フィルターを表示 | リポジトリレベルで非公開フィルターにアクセス |

### アクティビティ
| 名前 | 説明 |
|----------------------|--------------|
| アクティビティを表示 | アクティビティの記録とシステムイベントにアクセスできます。アクティビティには、非公開のコレクション、アイテム、タクソノミーに関する情報が含まれる場合があります。


#### ** コレクションレベル **

## コレクション

コレクションレベルの権限には、すべてのコレクションに影響する**全体**と、1つのコレクションだけに影響する**特定**という2つの対象があります。そのため、すべてのコレクション、または一部のコレクションだけにアクセスできるユーザー権限グループを設定できます。したがって、以下のすべての権限はこれらの対象によって異なる場合があります。

### コレクション
| 名前 | 説明 |
|-----------------------------------|---------------|
| コレクションを管理 | コレクションを設定し、そのすべてのアイテム、メタデータ、フィルターを管理 |
| ユーザー権限を管理 | このコレクションに関するユーザー権限グループと権限を管理 |
| アイテムを一括編集 | このコレクションのアイテムに対して編集または一括追加を行います。「アイテムを編集」や「他のユーザーのアイテムを編集」などの他の権限がない場合、この権限は効果を持ちません。

### メタデータ
| 名前 | 説明 |
|------------------------|--------------|
| メタデータを編集 | このコレクションのメタデータを作成・編集 |
| メタデータを削除 | このコレクションのメタデータを削除 |
| 非公開メタデータを表示 | このコレクションの非公開メタデータにアクセス |
  
### フィルター
| 名前 | 説明 |
|----------------------|--------------|
| フィルターを編集 | このコレクションのフィルターを作成・編集 |
| フィルターを削除 | このコレクションのフィルターを削除 |
| 非公開フィルターを表示 | このコレクションの非公開フィルターにアクセス |


### アイテム
| 名前 | 説明 |
|-------------------------------|--------------|
| アイテムを編集 | このコレクションのアイテムを作成・編集 |
| アイテムを削除 | このコレクションのアイテムを削除 |
| 他のユーザーのアイテムを編集 | このコレクションで他のユーザーが作成したアイテムを編集 |
| 公開済みのアイテムを編集 | このコレクションの公開済みアイテムを編集 |
| 他のユーザーのアイテムを削除 | このコレクションで他のユーザーが作成したアイテムを削除 |
| 公開済みのアイテムを削除 | このコレクションの公開済みアイテムを削除 |
| 非公開アイテムを表示 | このコレクションの非公開アイテムにアクセス |

<!-- tabs:end -->

これらはTainacanに関連する権限です。[こちら](/ja/manage-user-roles)でユーザー権限グループを編集して、これらの権限を増減させる方法を確認できます。また、[こちら](/ja/manage-specific-capabilities)で、特定のコレクションにおける例外を削除または追加する方法を確認できます。
