# フィルターのテスト

## 基本

1. フィルターを最大限テストできるよう、コレクションまたはリポジトリのメタデータ設定画面で、既存の各メタデータタイプを少なくとも1つずつ作成する；
2. これらのメタデータに値を入力したアイテムもいくつか作成することをおすすめする。この時点では[テストインポーター](/ja/importers#テストインポーター)が非常に役立つことがある！
3. 異なるコレクションで、コレクションレベルの異なるフィルタータイプを作成する；
4. リレーションシップタイプのメタデータ用に少なくとも1つ、タクソノミータイプのメタデータ用に少なくとも1つのフィルターを作成する；
5. フィルター間でステータスやその他のテキストフィールドに異なるオプションを設定する；
6. _削除_、_順序変更_、_フィルターの編集_、または_無効化_の操作をテストする。

- [x] ページを再読み込みし、すべてが保存されたことを確認する；
- [x] フィルターの作成時の読み込み時間を確認する；
- [x] 各フィルターの**保存**にかかる処理完了までの時間を確認する；
- [x] **設定が反映されているか**、Tainacanの管理画面のアイテム一覧と、テーマでこのコレクションのアイテム一覧の両方で確認する；

## リポジトリレベル

1. 上記の手順を、リポジトリレベルのいくつかのフィルターについて繰り返す；
2. コレクションのフィルターページに移動する；
   - [x] フィルターが継承され、その設定が尊重されているか確認する；
   - [x] コレクションレベルでフィルターの順序を変更できるか確認する；
   - [x] Tainacanの管理画面のリポジトリレベルのアイテム一覧と、テーマでリポジトリのアイテム一覧（`/items`）にアクセスしたときの両方で、フィルターが表示されるか確認する；
