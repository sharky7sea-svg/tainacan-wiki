# メタデータのテスト

## 基本

1. 異なるコレクションで、コレクションレベルの異なるメタデータタイプを作成する；
2. 少なくともリレーションシップ、タクソノミー、複合、ユーザーの各メタデータタイプを1つずつ作成する；
3. メタデータ間で、次の項目に異なるオプションを設定する：

    * ステータス；
    * 一覧に表示；
    * 入力オプション（特に、*必須*、*複数*、または*一意*の入力オプションを確認する）；
    * その他のテキストフィールド；

4. _削除_、_順序変更_、_メタデータの編集_、または_無効化_の操作をテストする。

- [x] ページを再読み込みし、すべてが保存されたことを確認する；
- [x] メタデータの作成時の読み込み時間を確認する；
- [x] 各メタデータの**保存**にかかる処理完了までの時間を確認する；
- [x] **設定が反映されているか**、アイテム一覧とアイテム作成フォームで確認する；

> [!NOTE]
> _注1_: メタデータが「無効」になっていることと、「一覧に表示しない」とマークされていることは異なります。前者では、アイテムにメタデータを入力することさえできません。後者では、アイテム一覧での表示が変わるだけです。

> [!NOTE]
> _注2_: 複合メタデータの子の順序変更はそのグループ内でのみ機能し、現在、複合メタデータの子としてタクソノミーは許可されていません。

## リポジトリレベル

1. 上記の手順を、リポジトリレベルのいくつかのメタデータについて繰り返す；
2. コレクションのメタデータページに移動する；
   - [x] メタデータが継承されているか確認する；
   - [x] コレクションのメタデータ設定画面にアクセスしたとき、それらの順序を変更できるか確認する；
