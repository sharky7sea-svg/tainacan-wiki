# Tainacanのユーザー権限グループ

WordPressの管理者には、通常、次のユーザー権限グループがデフォルトで用意されています。

* **管理者** - サイトのあらゆるコンテンツを変更できるだけでなく、プラグイン、テーマ、その他のサイト設定も管理できる、システムの「何でもできる」ユーザーです。
* **編集者** - 投稿やコメントなど、サイトのコンテンツを編集するためのアクセス権と権限を持つユーザーです。画像のアップロード、カテゴリーの作成、その他同様の操作もできます。
* **投稿者** - コンテンツを作成し、自分の投稿を編集できるユーザーです。
* **寄稿者** - 投稿者に似ていますが、投稿を公開できず、より上位のユーザー権限グループが公開を担当します。画像などのメディアコンテンツを管理したり、カテゴリーを作成したりすることはできません。
* **購読者** - WordPressの管理画面では権限を持たず、サイト上で公開されているものだけを見るユーザーです。たとえば購読者限定の投稿を読める、ログイン可能なユーザーを管理するために使われます。

ただし、Tainacanをインストールすると、新しいユーザー権限グループが追加されます。以下で確認しましょう。

* **Tainacan Administrator** - *Tainacan管理者*：リポジトリ、そのアイテム、コンテンツに対する管理権限を持ち、新しいユーザー権限グループを設定したり、その権限を変更したりすることもできます。
* **Tainacan Editor** - *Tainacan編集者*：他のユーザーが作成したものも含め、アイテムとコレクションを作成、公開、編集できます。
* **Tainacan Author** - *Tainacan作成者*：コレクションとアイテムを作成・公開できますが、公開済みのアイテムや他のユーザーのアイテムを編集することはできません。

**Tainacanのユーザー権限グループは、WordPressの他のコンテンツを操作するために必要な権限を保証するものではありません**。そのため、ブログのコンテンツには干渉しないリポジトリ管理者を設定できます。

> [!NOTE]
> ただし、逆の場合はレベルによって異なります。*Tainacan管理者*はデフォルトではWordPress管理画面に対する権限を持ちませんが、*WordPress管理者*は自身の権限に加えて、*Tainacan管理者*が持つすべての権限を持ちます。*WordPress編集者*も、*Tainacan管理者*が持つすべての権限を持ちます。一方、*Tainacan作成者*はデフォルトでは、WordPress管理画面において*WordPress購読者*と同じレベルの権限を持ちます。

ユーザーにどの種類のユーザー権限グループを割り当てるのが望ましいか、いくつかの状況を見てみましょう。

1. ユーザーがTainacanで自分のアイテムだけを作成・編集する権限を持ち、他のユーザーのアイテムやブログ・サイトのコンテンツには触れないようにする場合、適切なユーザー権限グループはおそらく*Tainacan作成者*です。
2. ユーザーがTainacanのリポジトリを完全に管理する権限を持ち、WordPressサイトは変更できないようにする場合、ユーザー権限グループは*Tainacan管理者*にする必要があります。
3. ユーザーがTainacanのアイテムを作成・編集すると同時に、WordPressで投稿を作成・モデレートできるようにする場合、最も適切なユーザー権限グループは*編集者*（WordPress）でしょう。
4. ユーザーがTainacanリポジトリ全体を管理できる一方、WordPressでは自分のアイテムだけを編集できるようにする場合、そのユーザーは*投稿者*（WordPress）にし、[ユーザー権限グループの設定ページ](/ja/manage-user-roles)を使ってユーザー権限グループを編集し、Tainacanに関する必要な権限を付与します。

Tainacanの権限がこのように設計されているのは、デフォルトでは、ユーザー権限グループが持つWordPress関連の権限を変更できないためです。ただし、WordPressにあるさまざまな権限・ユーザー権限グループ設定プラグイン（[こちらでいくつか確認できます](https://wordpress.org/plugins/search/user+roles/ ':ignore')）を使えば、これは完全に可能です。
