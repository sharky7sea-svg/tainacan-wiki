# このWikiへの貢献

このページにたどり着いたなら、私たちのWikiへの貢献を考えていることでしょう :smile: 。すばらしいことです！フリーソフトウェアのプロジェクトとして、Tainacanは**研究**、**コード**、**翻訳**、そして**ドキュメント**など、さまざまなレベルでの協力という原則に基づいています。ユーザーとして、資料をより明確で利用しやすくするために、価値ある貢献をすることができます。

ただし、貢献するには、私たちのドキュメントツールに少し慣れる必要があります。心配はいりません。このページでは、質の高い貢献を難なく行えるよう、必要な支援を提供します。このページでは次の内容を説明します：

* [GitHubでファイルを直接編集する](#githubでファイルを直接編集する)
* [Wiki記事のMarkdown構文の仕組み](#markdownの書式に慣れる)
* [Wikiでテストと高度な貢献を行う方法](#docsifyを使った高度な貢献)
* [Wikiのファイル構造の仕組み](#wikiの構造を理解する)

## GitHubでファイルを直接編集する

私たちのWikiは、次のGitHubリポジトリで完全にホスティングされています：https://github.com/tainacan/tainacan-wiki。部分的な貢献をするためにGitの豊富な経験は必要ありません。プラットフォーム自体がプロセスの大部分を簡単にしてくれます。たとえば、記事にスペルミスを見つけた場合は、ページの右上に表示される**GitHubで編集（Edit on github）**ボタンをクリックしてください。このページの「ソースコード」へリダイレクトされます：
 
![鉛筆の形をした編集ボタンが強調表示された、GitHubのコンテンツ編集ページのスクリーンショット。](/_assets/images/contributing.png)

ブラシの形をした編集ボタンをクリックすると、希望する変更を行い、フォームの最後で提案する変更内容を説明できます。変更案を送信すると、GitHubは内部であなたのために*Fork*を作成し、*Pull-Request*を適用します。

ページの作成、画像・タブ・動画の挿入、Wikiのナビゲーション構造の変更などを含む、より複雑な貢献については、[Docsifyを実行する手順](#docsifyを使った高度な貢献)に従うことをお勧めします。

## Markdownの書式に慣れる

多くの共同作業システムでは、編集者が作業しやすくなるよう、一定の書式規則を採用しています。私たちのWikiでは、そのために**`markdown`**言語を使用していますが、いくつかの追加機能も利用しています。この仕組みは、特定のテキストをどのように表示するかをソフトウェアに伝えるための構文とキーワードで構成されています。

### テキストのどこでも機能する:

| 内容                                      | 書く内容                                                   | 表示結果                         |
|---------------------------------------------|-----------------------------------------------------------|---------------------------------------|
| 斜体、太字、またはその両方のテキスト       | `*斜体*, **太字** または ***両方***`                       | *斜体*, **太字** または ***両方*** |
| 整形済みテキスト                             | ``ここに関数名を記述します``                              | `ここに関数名を記述します`       |
| Wikiページへのリンク                         | `[メインページ](/ja/README)`                              | [メインページ](/ja/README)  |
| セクションへのリンク                         | `[コレクションの作成](/ja/collections#コレクションの作成)` | [コレクションの作成](/ja/collections#コレクションの作成) |
| Webサイトのアドレスへの参照                  | `https://tainacan.org`                                    | https://tainacan.org                                   |
| カスタム名を付けたリンクへの参照             | `[Tainacan公式サイト](https://www.wikipedia.org/)`        | [Tainacan公式サイト](https://www.wikipedia.org/) |
| テキスト内のコメント                         | `<!--このコメントはページには表示されず、ソースコード内にのみ表示されます-->` | <!--このコメントはページには表示されず、ソースコード内にのみ表示されます-->  |

### 行頭でのみ機能する:

| 内容                    | 書く内容                              | 表示結果                                                     |
|-------------------------|----------------------------------------|-------------------------------------------------------------------|
| セクション見出し        | `## レベル2`                           | <h2>レベル2</h2>                                                  |
| セクション見出し        | `### レベル3`                          | <h3>レベル3</h3>                                                  |
| セクション見出し        | `#### レベル4`                         | <h4>レベル4</h4>                                                  |
| セクション見出し        | `##### レベル5`                        | <h5>レベル5</h5>                                                  |
| セクション見出し        | `###### レベル6`                       | <h6>レベル6</h6>                                                  |
| 箇条書き                | `* これは項目です`<br>`* これは別の項目です`<br>&nbsp;&nbsp;`* 項目の中の項目` | <ul><li>これは項目です</li><li>これは別の項目です<ul><li>項目の中の項目です</li></ul></li></ul> |
| 番号付きリスト          | `1. これは項目です`<br>`2. これは別の項目です`<br>&nbsp;&nbsp;`1. 項目の中の項目` | <ol><li>これは項目です</li><li>これは別の項目です<ol><li>項目の中の項目です</li></ol></li></ol> |
| チェックリスト          | `- [ ] これは項目です`<br>`- [x] これは別の項目です`<br>&nbsp;&nbsp;`- [ ] 項目の中の項目` | <ul class="task-list"><li class="task-list-item"><label><input disabled="" type="checkbox">これは項目です</label></li><li class="task-list-item"><label><input checked disabled="" type="checkbox">これは別の項目です</label><ul class="task-list"><li class="task-list-item"><label><input disabled="" type="checkbox">項目の中の項目です</label></li></ul></li></ul> |
| 強調表示                | `> これは重要な注記です。`                | <blockquote><p>これは重要な注記です。</p></blockquote> |
| アラート                | `> [!WARNING] **警告**: これは慎重に扱うべき注記です。` | <div class="callout warning"><p><strong>警告</strong> これは慎重に扱うべき注記です。</p></div>              |
| ノート                  | `> [!NOTE] **注記**: これは補足的な注記です。` | <div class="callout note"><p><strong>注記</strong>: これは補足的な注記です。</p></div>  |
| ヒント                  | `> [!TIP] **ヒント**: これは役に立つ注記です。` | <div class="callout tip"><p><strong>ヒント</strong>: これは役に立つ注記です。</p></div>  |
| 重要                    | `> [!IMPORTANT] **重要**: これは適切な注記です。` | <div class="callout important"><p><strong>重要</strong>: これは適切な注記です。</p></div>  |
| 危険                    | `> [!CAUTION] **危険**: これは緊張を伴う注記です。` | <div class="callout caution"><p><strong>危険</strong>: これは緊張を伴う注記です。</p></div>  |

### 区切り線

単純に線でセクションを区切るには、次を使用します：

```
------
```

次のように表示されます：

------

> 注：この記号と他のテキストの間には、少なくとも1行の空白を入れてください。そうしないと見出しとして解釈されます。

### 画像
| 内容                    | 書く内容                              | 表示結果                                                     |
|-------------------------|----------------------------------------|-------------------------------------------------------------------|
| 画像と説明              | `![Tainacanのロゴ](../_assets/images/logo_tainacan.png)` | ![Tainacanのロゴ](../_assets/images/logo_tainacan.png) |
| 画像と説明、サイズ変更  | `![Tainacanのロゴ](../_assets/images/logo_tainacan.png ':size=50')` | ![Tainacanのロゴ](../_assets/images/logo_tainacan.png ':size=50') |

`:size=50`を単一引用符で渡すのと同じように、CSSクラスを渡すこともできます。CSSクラスは3つあります：
- `:class=alignwide`: 画像の幅を広げ、ページのコンテンツの境界から少しはみ出すようにします；
- `:class=alignright`: 画像の左側にテキストを回り込ませます；
- `:class=alignleft`: 画像の右側にテキストを回り込ませます；

### 動画

メディアを埋め込むには、オンライン動画プラットフォームの大半で標準的な方法である`iframe`を使用します。たとえば、YouTube動画を埋め込むには：

```html
<iframe 
    width="560" 
    height="513" 
    src="https://www.youtube.com/embed/gFJfyHRKaE0?start=18"
    frameborder="0" allow="accelerometer; 
    autoplay; encrypted-media; gyroscope; picture-in-picture" allowfullscreen>
```
> [!NOTE] 幅（560px）、高さ（513px）、動画の開始時間（18秒）が設定されていることに注意してください。

結果は次のようになります：

<iframe width="560" height="513" src="https://www.youtube.com/embed/gFJfyHRKaE0?start=18" frameborder="0" allow="accelerometer; autoplay; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

### コードの断片

整形済みのコード断片を表示するには、`markdown`自体にその機能がありますが、いくつかの言語を強調するディレクティブを追加することもできます。目的のコードの前後を3つのバッククォート ` ``` ` で囲むだけです。たとえば`php`のコードの場合は、` ```php `で始めます。結果は次のようになります：

```php
<?php
function foo($arg_1, $arg_2, /* ..., */ $arg_n)
{
    echo "Example function.\n";
    return $retval;
}
?>
```

### タブ

私たちのWikiには、`markdown`のほかにタブを描画する機能があります。タブは、同じページ内のコンテンツをセクションに分けるのに役立ちます。たとえば、次のコードです：

```markdown
<!-- tabs:start -->

#### ** タブ1 **

タブ1の内容

#### ** タブ2 **

タブ2の内容

#### ** タブ3 **

タブ3の内容

<!-- tabs:end -->

```

次のように表示されます：
<!-- tabs:start -->

#### ** タブ1 **

タブ1の内容

#### ** タブ2 **

タブ2の内容

#### ** タブ3 **

タブ3の内容

<!-- tabs:end -->

### 折りたたみ

長いコンテンツを折りたたみ可能な領域に隠すには、`HTML`タグの`<details></details>`と`<summary></summary>`を使用します。たとえば：

```
<details>
<summary>折りたたみ（クリックして展開）</summary>

- ここにMarkdownコンテンツを記述します
- 必要なものを追加します

</details>
```

次のように表示されます：
<details>
<summary>折りたたみ（クリックして展開）</summary>

- ここにMarkdownコンテンツを記述します
- 必要なものを追加します

</details>

> [!NOTE] `HTML`コードと`markdown`の間には、空白行があることに注意してください。

### 表

`markdown`で表を作成する方法には、やや制限があります。例を示します：

```
| 見出し1      | 見出し2      |
|---------------|---------------|
| データ1       | データ2       |
| データ3       | データ4       |
```

次の表が生成されます：

| 見出し1      | 見出し2      |
|---------------|---------------|
| データ1       | データ2       |
| データ3       | データ4       |

Markdownの表の中に改行を入れるには、`HTML`タグの`<br>`を使用します：

```
| 見出し1      | 見出し2          |
|---------------|--------------------|
| データ1       | データ2           |
| データ3       | データ4<br>データ5 |
```

次の表になります：

| 見出し1      | 見出し2          |
|---------------|--------------------|
| データ1       | データ2           |
| データ3       | データ4<br>データ5 |

## Docsifyを使った高度な貢献

ここまでに説明したことはすべて[GitHubから直接編集](#githubでファイルを直接編集する)できますが、画像やタブなど、Wikiに送信されて初めて表示できる高度な機能がどのようになるかを予測するのは難しいものです。このような機能や、ナビゲーション構造の変更など、その他の高度な貢献については、追加の知識が必要になりますが、ローカルマシンでコンテンツをテストすることをお勧めします。

### 環境を準備する

マシンには次のソフトウェアをインストールしておく必要があります：

* Git
* NodeJS

まず、GitHubで私たちのリポジトリを*Fork*します：

![Forkの作成ボタンが強調表示された、GitHubのWikiページのスクリーンショット。](/_assets/images/contributing_2.png)

ローカルコピーをCloneしてアクセスします。ここでは、GitHubで作成したアカウントを使って、すでに[Gitの初期設定](https://git-scm.com/book/pt-br/v1/Primeiros-passos-Configura%C3%A7%C3%A3o-Inicial-do-Git)を行っているものとします：

```
git clone https://github.com/SEU_NOME_DE_USUARIO/tainacan-wiki
cd tainacan-wiki
```

次のコマンドにより、あなたの*Fork*をWikiの元のリポジトリから今後提供される更新と同期できるようになります：

```
git remote add upstream https://github.com/tainacan/tainacan-wiki.git
```

次に、Wikiの作成を支援するフレームワークであるDocsifyの`CLI`をグローバルにインストールします：

```
npm i docsify-cli -g
```

リポジトリのディレクトリ（`cd tainacan-wiki`、または必要な任意のパス）にいることを確認し、Docsifyサーバーを起動します：

```
docsify serve
```

これにより、通常はポート`http://localhost:3000`でローカルテストサーバーが起動します。ブラウザーでこのアドレスにアクセスすると、ローカルコピーで編集した後のWikiのプレビューが表示されます。リポジトリ内のファイルを変更して保存すると、その変更はこのアドレスに自動的に反映されます。

### 最初のPull Requestで貢献する

最後のコマンドを除く上記の手順は、1回だけ実行すれば十分です。ここでは、Wikiのファイルに変更を提案する方法を詳しく説明します。たとえば、[ホスティング](/ja/hosting)について情報を追加したいとします。この日本語版のファイルは`/ja/hosting.md`にあり、ブラウザーのアドレスバーで確認できます。

Wikiの公式リポジトリで行われた可能性のある変更をローカルリポジトリに反映してから始めるのがよい方法です：

```
git fetch upstream
git merge upstream/master
```

変更したい内容を編集し、ファイルを保存します。次に*Fork*を更新します：

```
git add .
git commit -m "Atualiza o conteúdo da página de hospedagem com mais opções."
git push
```

GitHub上の自分のリポジトリで変更を確認できるはずです。次に[Wikiの公式リポジトリ](https://github.com/tainacan/tainacan-wiki)へ移動し、「Pull Requestを作成（Criar Pull Request）」をクリックします：

![Pull Requestの作成ボタンが強調表示された、GitHubのWikiページのスクリーンショット。](/_assets/images/contributing_3.png)

*Fork*を変更元として選択し、変更内容を要約した説明を書くことができます。

![Forkの変更元ブランチを選択するオプションを示した、GitHubのWikiページのスクリーンショット。](/_assets/images/contributing_4.png)

リクエストを作成したら、チームのレビューを待つだけです！

## Wikiの構造を理解する

これでWikiへの変更を貢献・テストできるようになったので、リポジトリにある`markdown`ファイルを、https://tainacan.github.io/tainacan-wiki/#/ja/ にホスティングされているサイトへ変換するDocsifyの仕組みについて、もう少し理解しましょう。

リポジトリのファイル構造を見ると、次のようなページやファイルなどがあります：

```
/_assets
/dev
    README.md
    _sidebar.md
/pt-br
    /_assets
    /dev
        README.md
        _sidebar.md
    CONTRIBUTING.md
    README.md
    _coverpage.md
    _navbar.md
    _sidebar.md
    collections.md
CONTRIBUTING.md
README.md
_coverpage.md
_navbar.md
_sidebar.md
collections.md
index.html
style.css
```

いくつかについて説明します：

* **/_assets**: 画像やその他のメディアファイルを保存するフォルダーです。Wikiのより深い階層にも、その範囲に関連するファイルを保存するために存在します；
* **/dev**: 開発者向けドキュメントに関するWikiの部分を保存するフォルダーです。この分離は、Wikiの大量のコンテンツを整理するのに役立ちます。将来、Wikiの一部ごとに他の専用フォルダーを作成することもできますが、その場合はそこに置かれるファイルへの参照を調整する必要があります；
* **/pt-br**: ブラジルポルトガル語に翻訳されたWikiのドキュメントを保存するフォルダーです。Wikiの残りのほぼすべてのファイルとフォルダーがここに複製されていることに注意してください。このフォルダー内のファイルに翻訳版がない場合、ユーザーはルートフォルダーの対応するファイルへリダイレクトされます；
* **CONTRIBUTING.md**: Wikiへの貢献を希望する人のための手順です。日本語版では、このファイルは`/ja/CONTRIBUTING.md`にあります；
* **README.md**: `/`にアクセスしたときに読み込まれるWikiのホームページです。GitHubにもこのファイルを紹介用ファイルとして認識させるため、READMEという名前を使用しています。日本語版は`/ja/README.md`にあり、`/ja`にアクセスすると読み込まれます。`/dev`フォルダー内にもこのファイルの版があり、開発者セクションのホームページになります；
* **_coverpage.md**: ホームページの上に読み込まれるカバーページです；
* **_navbar.md**: Wikiの上部バーです。現在は公式サイトへのリンクと、サイトの言語を選択するドロップダウンを含みます。これはDocsifyによってレンダリングされる特別なページで、たとえばサブリストをドロップダウンに変換します；
* **_sidebar.md**: サイドバーに表示されるリンクの一覧です。`/pt-br`フォルダーにも翻訳された内容のものがありますが、`/dev`と`/dev/pt-br`フォルダーにも版があります。これにより、開発者セクションのファイルを移動すると、そのテーマ専用のリンク一覧が表示されます。
* **collections.md**: Wikiに存在する多数の通常ページの1つの例です。これらのページには通常、見出しによって独自の階層が定義され、ページに入るとサイドバーにも表示されます；
* **index.html**: Docsify、プラグイン、インポートを設定するためのファイルです。何をしているか分からない場合は、ここを変更しないことをお勧めします！
* **style.css**: Wikiの外観をカスタマイズするサイトのCSSスタイルシートです。

この構造と、Docsifyのローカルテストサーバーによる変更を積極的に試して、概念に慣れることを強くお勧めします。詳しくは[Docsifyのドキュメント](https://docsify.js.org/)を参照してください。
