# インポーターのテスト

Tainacanには、開発者がプラグインとして作成できるものも含め、さまざまなインポーターがあります。このドキュメントでは、最もよく使われていると考えられる[CSVインポーター](/ja/importers#csvインポーター（アイテム）)を扱います。

## 基本

1. リポジトリのメニューからアクセスできる、インポーターのページに移動する；
2. CSVインポーターを選択する；
3. テストするCSVファイルを選択する。ファイルには、インポートでよくあるケースをいくつか含めることが重要である。手元にない場合は、[こちらのファイル](http://oficinas.tainacan.org/ ":ignore")を使用できる；
4. フォームに入力し、インポート先コレクションを選択してCSVファイルをアップロードする；
5. `次へ（Próximo）`をクリックする；
   - [x] マッピング画面に入ったとき、前のページで設定した区切り文字に従って列が正しく分割されているか確認する。
   - [x] このコレクションに存在するメタデータがマッピングのセレクターで利用できるか確認する。
6. メタデータのマッピングを入力する。コレクションにメタデータがまだ設定されていない場合は、[インポーターに作成させる](#マッピングでメタデータを作成)。すでに設定されている場合は、各タイプに適切なマッピングを行う；
   - [x] メタデータをマッパーの列に関連付けるたびに、そのメタデータが他のセレクターで利用できなくなることを確認する；
7. `実行（Executar）`をクリックしてインポーターを実行する；
   - [x] コレクションの「タイトルの主メタデータ」に列を1つもマッピングしていない場合、その設定を促す警告が表示されることを確認する；
   - [x] インポーターの実行が完了したら、プロセスページでログ（ログファイル）を確認し、警告がなかったか確認する；
   - [x] メタデータタイプが正しくマッピングされ、画像が読み込まれ、空のタクソノミーメタデータがある場合は新しいタームが作成されたことを確認する；

## アイテムの置換

1. 前回インポートを行ったコレクションに移動する；
2. コレクション画面の右上隅にある`エクスポート`ボタンをクリックする；
3. コレクションをCSVとしてエクスポートする；
4. 任意のエディターでエクスポートしたCSVファイルのいくつかの行の内容を変更する。アイテムのメタデータを変更したり、処理を速くするために必要であればいくつかの行を削除したりできる；
5. リポジトリのメニューからアクセスできる、インポーターのページに移動する；
6. CSVインポーターを選択する；
7. 同じコレクションをインポート先に指定し、変更したCSVファイルをアップロードする；
8. フォームで「重複アイテム（Item Repetido）」のオプションを`更新`に設定することを忘れない；
9. `次へ（Próximo）`をクリックする；
10. メタデータのマッピング画面で、前回のインポートでメタデータに使用したものと同じ列を維持する；

- [x] 特殊フィールド`special_item_id`が検出されたか確認する。

11. `実行（Executar）`をクリックしてインポーターを実行する；
    - [x] インポーターの実行が完了したら、プロセスページでログ（ログファイル）を確認し、警告がなかったか確認する；
    - [x] 行を変更したアイテムがインポート処理で更新されたことを確認する；

## マッピングでメタデータを作成

1. リポジトリのメニューからアクセスできる、インポーターのページに移動する；
2. CSVインポーターを選択する；
3. テストするCSVファイルを選択する。この場合、[特殊フィールド](/ja/importers#特殊な列)を使った**メタデータ関連の設定**が含まれていることが理想的である。[このページ](http://oficinas.tainacan.org/)の最後のリンクに例があるが、[インポーターのドキュメント](/ja/importers#メタデータの自動作成)を参考にして独自の設定を作成することもおすすめする；
4. **メタデータがまだ設定されていないコレクション**を選択してフォームに入力し、CSVファイルをアップロードする；
5. `次へ（Próximo）`をクリックする；
6. マッピングで、インポーターがメタデータを作成できるようにする；
7. マッピング一覧の下にある`メタデータを作成（Criar Metadado）`オプションをクリックし、この画面でテスト用のメタデータを1つだけ作成する；
   - [x] メタデータの作成が完了したとき、そのメタデータがマッピングのセレクターで利用できるか確認する；
8. インポーターに作成させる代わりに、作成したばかりのメタデータを使ってマッピングするメタデータを選択する；
9. `実行（Executar）`をクリックしてインポーターを実行する；
   - [x] インポーターの実行が完了したら、プロセスページでログ（ログファイル）を確認し、警告がなかったか確認する；
   - [x] 「複数の値を許可」、「ステータス」、「新しいタームの追加を許可」などの設定を含め、メタデータタイプが正しく作成されたことを確認する；
