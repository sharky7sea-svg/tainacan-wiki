# PDFコンテンツのインデックス化

0.12では、アイテムのドキュメントとしてアップロードされたPDFファイルのテキストをインデックス化する実験的な機能をリリースしました。これにより、ユーザーはPDF内のテキストを検索できます。

この機能はまだベータ版であり、すべての環境やPDFファイルで動作するとは限らないため、デフォルトでは有効にしないことにしました。ただし、ユーザーにはこの機能を有効化し、検証に協力していただくことをおすすめします。

## 有効化

この機能を有効化するには、[Tainacan設定ページ](/ja/settings-page#_1-検索とパフォーマンス)に移動し、「PDFコンテンツ」設定を変更します。または、`wp-config.php`ファイルにアクセスできる場合は、ファイルを編集して次の行を追加します：

```
define('TAINACAN_INDEX_PDF_CONTENT', true);
```

この機能を有効にすると、*その時点以降に*アップロードされたPDFファイルの内容がインデックス化され、検索可能になります。

## 検索

インデックス化されたPDFの内容は、すべてのメタデータを検索する「テキスト検索」機能を使用するたびに検索されます（有効な場合は[検索エンジン](/dev/search-engine.md)を参照してください）。

高度な検索を使用してPDFの内容を検索することもできます。「ドキュメント」という新しいオプションがあり、インデックス化されたPDFファイルの内容を検索します。

## 既存のPDFファイルをインデックス化

この機能を有効にした時点でリポジトリにPDFファイルが多数ある場合は、それらすべてをインデックス化するコマンドを実行できます。これは[WP-CLI](/ja/tainacan-cli)ツールを使用して行います。

サーバーにアクセスし、次のように入力します：

```
wp tainacan index-content --collection=all
```

特定のコレクションのPDFだけをインデックス化する場合は、次のように入力します：

```
wp tainacan index-content --collection=<id of collection>
```

このコマンドの使用方法についてヘルプを表示するには、次のように入力します：

```
wp tainacan index-content --help
```
