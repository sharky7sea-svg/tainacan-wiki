# アイテムのテスト

## 基本

1. コレクションを開く；
2. そのコレクションで、異なる種類のドキュメントを使用してアイテムを作成する；
3. 複数のアイテムのサムネイルを編集する；
4. 複数のアイテムで添付ファイルを編集および追加する；
5. いずれかのアイテムのページで、コメントを許可するオプションを変更する；
6. `保存` をクリックする；
7. テーマでアイテムのページにアクセスする。

- [x] コレクションを開くときの読み込み時間を確認する；
- [x] アイテムを作成するときの読み込み時間を確認する；
- [x] コレクションページのすべての要素が正しく表示されるか確認する；
- [x] アイテム作成ページのすべての要素が正しく表示されるか確認する；
- [x] 各アイテムを**保存**または**公開**するときの処理完了までの時間を確認する；

## メタデータの入力

1. コレクションを開く；
2. そのコレクションの複数のアイテムを編集し、メタデータフィールドに入力する；
3. 必須としてマークされたメタデータに_入力しない_場合をテストする；
4. タクソノミータイプのメタデータフィールドへの入力と、新しいタームの作成をテストする；
5. 数値または日付タイプのメタデータフィールドに無効な値を入力するテストを行う；
6. _最初のコレクション_でアイテムを作成した後、_別のコレクション_でリレーションシップメタデータへの入力をテストする。

- [x] アイテム作成ページで、リポジトリレベルとコレクションレベルのすべてのメタデータが入力用に正しく表示されるか確認する；
- [x] 特定のメタデータに設定した入力ヒントが正しく表示されるか確認する；
- [x] 各アイテムを**保存**または**公開**するとき、**必須メタデータの入力**に関する警告が正しく機能するか確認する；

7. 複数の値を受け付ける_複合メタデータ_への入力をテストする。最初はフィールドが空で、値を追加するボタンだけが表示される。追加すると、子メタデータを含む最初の入力グループが表示される；

- [x] 必須としてマークされた子メタデータが、フォームのエラー一覧にエラーを生成するか確認する；
- [x] 子メタデータの表示順が、メタデータ設定画面で設定した順序になっているか確認する。

8. _「アイテムの作成者をデフォルトとして設定」（Definir o item do autor como padrão）_機能を、ユーザーメタデータタイプについてテストする。アイテムを作成すると、このフィールドに入力された状態になるはずである。
