# コレクションのテスト

## 基本

1. 2つ以上のコレクションを作成する
2. サムネイルとヘッダー画像を含め、各フィールドに入力する；
3. 各コレクションに異なるステータスを設定する。たとえば「公開」と「非公開」などを設定する（「下書き」は使用できない）；
4. `完了（Concluir）` をクリックして変更を保存する；
5. コレクション一覧に移動し、ステータスに応じてコレクションが正しいタブに表示されているか確認する；
   - [x] _コレクションの作成_ と _コレクション一覧_ 画面の読み込み時間を確認する；
   - [x] コレクションを**完了**または**保存**するときの処理完了までの時間を確認する；

## テーマでのコレクション表示とアイテムへのコメント

1. コレクションの表示モードを設定し、必要な数だけ選択する；
2. 「コメントを許可（Permitir comentários）」オプションを設定し、アイテムへのコメント設定を有効にする；
3. `完了（Concluir）` をクリックして変更を保存する；
4. 右上隅の目の形をしたボタンをクリックして、テーマでコレクションページ（デフォルトではコレクションのアイテム一覧）にアクセスする；

- [x] ページのすべての要素が正しく表示されるか確認する；
- [x] 有効にした表示モードが利用でき、デフォルトとして選択したモードが最初に表示されるか確認する；

5. 管理画面に戻り、今度はこのコレクションのアイテムを編集してみる：

- [x] 手順 _2_ で設定した内容に応じて、アイテム編集ページにコメントを変更するオプションがあるかどうか確認する；

6. コレクション設定に戻り、「カバーページ（Página de capa）」オプションを有効にする。コレクションのカバーページとして任意のページを選択する；
7. `完了（Concluir）` をクリックして変更を保存する；
8. テーマでコレクションページに再度アクセスする；

- [x] 選択したページがこのコレクションのカバーページとして設定されているか確認する；

9. 設定に戻り、使用しない場合は「カバーページ（Página de capa）」オプションを無効にする。

## コレクションの `slug`

1. コレクション編集フォームで `slug` を任意の値に変更する；
2. `完了（Concluir）` をクリックして変更を保存する；
3. 右上隅の目の形をしたボタンをクリックして、テーマでコレクションページにアクセスする；

- [x] ページのリンクが設定した `slug` を使って記述されているか確認する？

## コレクションの継承

1. コレクションにいくつかのメタデータとフィルターを作成する；
2. 別のコレクションの設定に移動し、最初のコレクションを「ルートコレクション」として選択する；
3. このコレクションのメタデータページとフィルターページにアクセスする；
   - [x] メタデータとフィルターが継承されているか確認する？
