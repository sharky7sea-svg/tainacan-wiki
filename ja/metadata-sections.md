# メタデータセクション

バージョン0.19以降、Tainacanには**メタデータセクション**機能があります。これは、長いメタデータ一覧を視覚的・構造的なグループに整理する方法で、アイテムのデータをより強力にカタログ化できます。管理画面では、メタデータセクションは _折りたたみ可能な_ パネルとして表示されますが、アイテムの公開ページでは、テーマの設定に応じてさまざまな方法で表示できます。たとえば、タブとして表示したり、あるセクションを他のセクションより視覚的に目立たせることができます。

この記事では、次の内容について説明します。

- メタデータセクションの[一般的な特徴](#メタデータセクションの特徴)。
- メタデータセクションを[作成・編集する方法](#セクションの作成と編集)。
- メタデータセクションを[削除する方法](#セクションの削除)。
- アイテムの公開ページで[メタデータセクションを表示する方法](#アイテムページでのセクションの表示)。

ここでは、メタデータの概念と編集フローをすでに理解していることを前提とします。そうでない場合は、[メタデータ](/ja/metadata)を参照してください。

## メタデータセクションの特徴

- すべてのセクションには**名前と説明**があり、設定されていればアイテム入力ページに表示されます。
- すべてのコレクションには、作成時からセクションが1つあります。これは**_デフォルトセクション_**と呼ばれ、最初の名前は「メタデータ」です。
- **_デフォルトセクション_は削除できず**、その公開状態は常にコレクションの公開状態に従います。
- その他の**セクションは公開または非公開**にでき、その公開状態はその中にあるメタデータの公開状態にも影響します。
- セクションは無効にできます。無効にすると、データ自体は存在し続けますが、アイテムの表示時や入力時にそのメタデータは表示されません。
- セクションには無制限の数のメタデータを含めることができ、それらをいつでも別のセクションへ移動できます。
- セクションは、**メタデータが含まれていない場合にのみ削除できます**。
- セクションの順序も変更できます。
- **リポジトリレベルのメタデータ設定にはセクションがありません**。コレクションに継承されると、リポジトリのメタデータは _デフォルトセクション_ に表示されます。必要であれば、そこから他のセクションへ並べ替えることができます。

## セクションの作成と編集

前述のとおり、メタデータとは異なり、セクションはコレクションレベルにのみ存在します。また、すべてのコレクションにはすでにデフォルトセクションがあります。したがって、新しいセクションを作成するには、次の手順を行います。

1. コレクションのメタデータ設定ページにアクセスします。
2. 「利用可能なメタデータタイプ」の一覧の下に、「新しいメタデータセクションを作成」ボタンがあります。このボタンをクリックするか、セクション間の領域へドラッグ＆ドロップできます。
3. クリックするとセクションの編集フォームが表示され、少なくともセクション名を入力する必要があります。その他のフィールドは任意です。
4. セクションを作成すると、そのタイトルの下にメタデータを受け入れられる新しい領域が表示されます。この領域には、新しいメタデータ（メタデータタイプをそこへドラッグする）と、デフォルトセクションまたはすでに作成した他のセクションにある既存のメタデータの両方を移動できます。
5. セクション間の順序は、ドラッグ＆ドロップで移動するか、ドラッグアイコンの横にある矢印を使って変更できます。

## セクションの削除

セクションを削除できるのは、それがデフォルトセクションではなく、かつその中にメタデータが存在しない場合だけです。

1. まず、目的のセクションにある既存のメタデータを移動または削除します。
2. セクションの右隅にあるゴミ箱ボタンをクリックします。

## アイテムページでのセクションの表示

Tainacanの管理画面では、セクションはアイテムページのメタデータ一覧における、より上位階層の区切りとして表示されます。アイテムの編集ページでは、この区切りを折りたたんで、すべてのメタデータを隠すこともできます。一方、アイテムの公開ページでは、セクションを表示する方法として考えられるものがいくつかあります。[テーマ開発者](/dev/creating-compatible-themes.md)は、[セクションを読み込む関数](https://github.com/tainacan/tainacan/blob/develop/src/classes/theme-helper/template-tags.php ":ignore")を使ってこれらのセクションを実装します。これが行われていない場合、メタデータは機能ごとの分離なしに表示されますが、セクション内の順序は維持されます。幸い、[Tainacan Interface](/ja/theme#tainacan-interface)と[Blocksy](/ja/theme#blocksy)の両方には、いくつかの表示例がすでに実装されています。以下の例ではTainacan Interfaceテーマを使用しますが、セクションがこれらに限定されるわけではないことを理解しておくことが重要です。

1. Tainacan Interfaceテーマを有効にして、コレクションの設定にアクセスします。
2. 設定フォームには、テーマ設定のある灰色の領域があります。そこで、セクションを表示するために使用するレイアウトを選択します。選択肢は次のとおりです。
   1. デフォルト - インデントとセクションを分ける線による単純な分割。
   2. タブ - 各セクションが1つのタブに含まれます。
   3. _折りたたみ_ - 各セクションが、エディターと同様の折りたたみ可能なパネルに含まれます。複数のパネルを同時に開けますが、最初は最初のパネルだけが開いています。
   4. アコーディオン - _折りたたみ_と同じですが、一度に開けるのは1つだけです。
3. 設定を保存し、テーマを有効にした状態で、サイト上のアイテムの公開ページにアクセスします。
