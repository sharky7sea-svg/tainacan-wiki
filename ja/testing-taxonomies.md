# タクソノミーのテスト

## 基本

1. 1つ以上のタクソノミーを作成する；
2. 作成した各タクソノミーに1つ以上のタームを作成する；
3. 各タクソノミーの少なくとも1つのタームに _ヘッダー画像_ をアップロードする；
4. **名前**、**説明**など、すべてのフィールドに入力する；
5. 各タクソノミーに少なくとも1つの階層レベルを作成する（子タームを追加する）；
6. 作成後、少なくとも1つのタクソノミーのステータスを変更する；
7. タクソノミー一覧に移動し、ステータスに応じてタクソノミーが正しいタブに表示されているか確認する；

- [x] _タクソノミーの作成_、_ターム一覧_、_タクソノミー一覧_ 画面の読み込み時間を確認する；
- [x] 各タクソノミーの**保存**にかかる処理完了までの時間を確認する；
- [x] 各タームの**保存**にかかる処理完了までの時間を確認する；

8. タクソノミーを削除してみる。ほかのタクソノミーやタクソノミーメタデータに変更があるか確認する；
9. 少なくとも1つのタクソノミーを1つのメタデータに関連付け、このタクソノミーで上記の操作を繰り返す；
10. 同じタクソノミーを同じコレクションの2つのメタデータに関連付けてみる。これは可能であってはならない。

## テーマでのターム表示

1. いずれかのタームの編集フォームを開く；
2. 「テーマで表示（Ver no Tema）」をクリックする；
   - [x] 画像と入力した説明を含め、タームのアイテム一覧が正しく表示されるか確認する；
   - [x] そのタームがタクソノミー型メタデータで設定されている可能性のあるアイテムが一覧に表示されているか確認する。

## 新しい親タームの設定

1. いずれかのタームの編集フォームを開くか、新しいタームを作成する；
2. 「親ターム（Termo Pai）」オプションを有効にし、親として選択できるタームを検索する；
3. `保存（Salvar）` をクリックして変更を保存する；
   - [x] 提示されたタームの中に、そのターム自身が表示されていないか確認する；
   - [x] 現在選択しているタームに子タームがある場合、階層を変更したときに一覧が正しく再読み込みされるか確認する；

## 新しいタームの許可

1. タクソノミーの設定フォームで「新しいタームを許可（Permitir Termos Novos）」オプションの選択を解除する；
2. `保存（Salvar）` をクリックして変更を保存する；
3. コレクションのメタデータ設定画面に移動する；
   1. 変更したタクソノミーをもとに、タクソノミータイプのメタデータを作成する。
   2. 「新しいタームを許可」オプションがなくなっていることを確認する。
4. コレクションのアイテム一覧に移動し、アイテムを作成または編集する；
   1. タクソノミータイプのメタデータに既存のタームを追加する。
   2. メタデータ編集フォームから、タクソノミーに新しいタームを追加してみる。
   - [x] タクソノミーの設定がメタデータの設定より優先されるため、タクソノミーに新しいタームを挿入できないことを確認する；
   - [x] アイテムのページを再読み込みし、選択可能なタームが保存されているか確認する
