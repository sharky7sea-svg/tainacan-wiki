# プラグイン

Tainacanは、_WordPress_の機能を新しい機能によって拡張する、_WordPress_用の_プラグイン_です。これは、ほとんどのユーザーのニーズに対応できる中核ソリューションを提供し、より具体的な要件に合わせるためのアドオンを選択できるようにするという、_WordPress_の理念の一部です。同じことはTainacan自体にも当てはまります。Tainacanはデジタルアーカイブの管理と展示に必要と考える機能のほとんどをデフォルトで提供しつつ、いくつかの追加機能を_Tainacanを拡張する追加プラグイン_として利用できるようにしています。

## 利用可能なプラグイン

現在、以下のプラグインがTainacanで利用できます：

- [PDF Exposer](/ja/plugin-pdf-exposer) - 「表示形式...」モーダル、つまりエクスポーザーまたは代替URLに、アイテムをPDFとして出力するオプションを追加します。
- [URLメタデータタイプ](/ja/plugin-metadata-type-url) - URLを受け付け、コンテンツの埋め込み版またはiframeを表示する追加のメタデータタイプを追加します。
- [追加表示モード](/ja/plugin-extra-view-modes) - 追加表示モードのデモ用テンプレートを多数追加します。独自の表示モードを作成する方法を学びたい開発者に最適です。
- [WordPress 3DHOP](/ja/plugin-3d-hop) - [3D HOP](http://3dhop.net/)を使用して、WordPressでインタラクティブな3Dモデルを表示できるようにします。

開発者で、何らかのソリューションによってTainacanを拡張したい場合は、[そのための開発者向けセクション](/dev/#plugin-development-or-extension)を確認し、ソースコードも参照することをおすすめします。ソースコードは学習のための優れた資料になります🤓。また、プラグインを作成してここに掲載したい場合は、[フォーラム](https://tainacan.discourse.group)でご連絡ください。

## プラグインのインストール

現在のところ、追加プラグインはWordPress公式のプラグインリポジトリに提出されていないため、Tainacan本体ほどインストールは簡単ではありません。ただし心配はいりません！基本的な方法は3つあり、どの方法でもインストールには管理者権限が必要です。まず、プラグインのコードを含む`.zip`ファイルをダウンロードします。通常はGitHubから入手できます。

### WordPress管理画面からプラグインをインストール

ダウンロードしたプラグインを画面上でインストールするには、WordPress管理画面のサイドバーにある「プラグイン」セクションへ移動し、「新規追加」をクリックします。プラグイン一覧が表示され、その上にある「プラグインのアップロード」ボタンから`.zip`ファイルを選択できます。

![WordPress管理画面からプラグインをインストール](/_assets/images/plugins_1.png)

### WP-CLIでプラグインをインストール

[WordPress CLI](https://wp-cli.org/#installing)がインストールされている場合は、さらに簡単です。_WordPress_のインストールフォルダーで、次のコマンドを実行するだけです：

```
wp plugin install /PATH/TO/YOUR/ZIP/FILE/plugin-name.zip
```

### サーバーに直接プラグインをインストール

サーバーのファイルにアクセスできる場合は、同じ処理を手動で行うこともできます。そのためには、`zip`ファイルを展開し、プラグインと同じ名前のフォルダーに入れて、その内容を`wp-content/plugins`フォルダーへ移動します。

## プラグインを有効化

プラグインをインストールしたら、WordPress管理画面のプラグイン一覧でも有効化する必要があることを忘れないでください。
